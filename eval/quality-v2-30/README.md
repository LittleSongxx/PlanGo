2026-09-09。只报告任务成功率TSR、事实支持率Groundedness；Token单独记录。

本批由独立上下文起草新案例，并按用户明确授权由独立子Agent审核金标与实际输出；主审核者使用两个独立分项助手，最后统一复核并汇总。**这是AI审核的受控评测，不是人工复核、真实商家履约、未见网站泛化或第三方榜单。** 同模型家族的多个上下文不等于独立模型交叉验证，原12例dev不混入成绩。

## 固定范围

- 15组新虚构资料、30例任务，6家族各5例；20例可交付任务、10例范围判断。源组内两题相关，不能将30题当成30个独立网站。
- 20例使用原始资料观测注入；10例使用实际Electron执行编辑、保存/重启、真实接受后丢响应、查询恢复及送达待核实。初始化的步行路线和未保存草案在 `runtime-fixtures.json` 显式声明，不算商家事实或预置成功。
- Actor使用本项目真实模型和既有预算，串行运行于独立SQLite/profile，只有模型与自有回环服务可访问。不执行真实交易，也未增加预算让失败过关。
- 冻结产品提交 `de37fecd3dc4d1792fe9efb11108126d4bfd5ef1`，140个产品/构建/依赖文件及安全模型配置，见 [product-freeze.json](product-freeze.json)。各批次记录实际采集器版本。
- 运行前复核纠正一项金标时间边界，并完善初始化契约和桌面覆盖，保留首次审查。金标最终30项均获AI批准，人工签核0。

## 计分与无效尝试

TSR要求运行前全部必要条件、禁止条件和副作用/虚假完成守卫通过，且有完整交付；产品自己的成功状态不能代替这些条件。错误澄清、缺交付及预算失败照计失败。

Groundedness检查所有实际回复与卡片的原子事实、来源、条件、单位、推导和输出时序。同题同义重复只计一次，已展示的错误不能被后来改正抹去；使用各题支持率的宏平均。零事实题为N/A，含事实的失败题仍评分。总支持事实/总事实另列，不能混作宏平均。

共保留39次尝试，最终每题只有1次有效主尝试。9次无效尝试经独立审查后另列：8次导入来源ID违反共享类型契约，所有受影响案例统一作废，不按结果挑选；1次连接错误发生于首条用户输入和模型调用之前。修复初始化/回环连通检查后仅替代这些无效尝试，旧输出和费用保留。未重跑有效产品失败挑最高分。

## 复核证据与复验

任务、来源、金标、运行初态分别在本目录JSON中。用户授权与AI审核边界见 [review-policy.json](review-policy.json)。`review/`保留本批虚构受控资料的评分包与独立审核，可离线核算；已检查没有配置密钥、真实主任务引用或Cookie/认证字段。原始SQL、profile和模型响应日志仍留私有 `output/quality-v2-30/session-20260909-r2/`：

- `gold-bundle.json`、`independent-gold-review.json`：运行前金标审批；旧session/r1保留首次审查。
- `fixture-adjudication.json`、`startup-adjudication.json`及两个invalid记录：替代原因及原始尝试绑定。
- `attempt-registry.jsonl`、各批次manifest、每题collection/模型日志/可见输出/独立SQL与桌面停点：真实运行记录。
- `output-bundle.json`：30题最终封存包；dataset SHA `21cb25bcc71a695b020bba54c51cec7db68a42f2e57dbdd7eaa3ac00f5602e5a`，product SHA `70c45c71dc631426fd001cf50dc48ec436cffc277089fa44369ee32c82aa9ed7`，collection SHA `12c26365d9d638b9d6a6909a5ebedfaba3d539b636b90a5e2042c472fe98323a`。
- 复核发现运输字段白名单遗漏原已采集的接受回执、保存基线及持久事件，故统一给10个桌面题补证据附录 `output-bundle-transport-amended.json`，collection SHA `ea2f16a56a8b6ef99aaae55170cc6bdbe34b2c122cd2b044fdea4b1c1f044029`。所有原始文件hash核对一致，原输出、金标、来源、状态及旧运输字段逐项不变；仅增加已有记录，不重跑产品。原包和初审均保留，补充后重新独立核对相关条件，不能把评审组包缺失误记成产品故障。详见[附录索引](transport-evidence-amendment.json)。
- `reviewed-cases/`及修订版本保留审查轨迹；独立主审核汇总后的完整审查可通过下列命令离线验证，无需运行模型或打开浏览器。


## 后续版本的边界

30题输出封存后才合入[通用友好提示修复](../plango-friendly-errors/README.md)。评分仍使用原版输出，没有重新渲染旧材料。该批现已揭示，后续可用于回归；不能将修复后的重复成绩称为新的未见测试成绩。

后续修复从跨案例共同原因出发，优先统一任务意图与证据需求、明确修改字段的持久补丁和输出事实边界；不添加题号、门店名或单题措辞专用规则。每项改动用原功能和新的反例验证，冻结后另采来源组评估泛化。
