| 资料分析误入定位流程 | 只覆盖旧读取/人均比价关键词，且原reasoning仅能比较人均价。增加明确的资料分析路由，复用当前持久页面来源与结果存储 | DEV-04条件核算98元；DEV-08保留180元餐费、2.4km/15分钟与20元余量，票价未知，完整总价仍null |

模型只提取带原文引用的金额、单位和条件；确定性验证原文位置、唯一候选、数值/单位、人数、日期时段，再用Decimal计算。短引文可以定位数字，但完整原文的单位与否定不能省略；持久结果保留展开后的完整出处。多商家/多套餐拼接、往返票价当单程、每位/多份价格当每份、不含服务费等反例保持未知或冲突。

套餐的原文明确覆盖2名成人，而用户仅说2人。因此实际回复是“若同行2人均符合条款中的成人范围，且遵守上述所给条款条件，可按一份核算”；不会默认为已确认年龄资格。结果范围为`source_analysis`，`business_completed=false`，没有查询实时商家供给或提交交易。
