## 实施的共享改动

- `TaskIntent`在原模型适配器和轮次预算内区分规划、读取、资料判断、操作和继续；同轮结果持久复用，目标切换保留已接受条件。没有增加操作授权或自治Agent团队。
- `RequirementOutput.field_evidence`要求本轮修改有原文出处；确定性边界校验单位、类型、有限值及清除冲突。真实模型输出不再被fallback空值覆盖，缺依据保留原值并澄清；非法时刻不截成另一个有效时刻。
- `planning_reset`与Runtime重入复用规范保留规则，解析/地理暂停时TripSpec仍在；旧计划、校验、审批和执行目标继续失效。真实Runtime、编译子图、SQLite与重启测试覆盖该链。
- 场所类别未知时不默认餐厅，通用优惠费用用消费范围表达，来源显式失效时间参与校验。原`SourceAnalysis`仍有窄场景限制，不能称已解决全部费用/条件判断。
- 现有collector/driver增加显式dataset、freeze、work与版本化小批协议；原30例默认与旧hash保护保留。两批使用同一追加预算账本，不分批续额度。
