# 4人聚会 Skill

## 何时命中
用户提到「几个人/朋友/聚会/局/4人/6人」等多人场景时激活。

## 规划建议
1. 玩乐先选可多人一起的：桌游/KTV/密室/球馆/展览。
2. 先核对实际人数、总预算/人均预算和共同忌口，再找合适桌位；4-6 人只是常见场景，不能默认代替人数确认。
3. 桌位、包厢低消与排队时间需有页面证据，未知时标明；热门不代表必然排队，不能保证在线取号可用。
4. 已有方案可由用户在分享界面发局域网链接收集意见，再明确要改哪站；不声称已发消息或所有人已同意。

## 软偏好
- 包厢、宽敞、适合聚会、氛围好、可拼桌。

## 取号边界
需要取号时可 read_skill 读取已启用的 dianping-queue；click/type 每步经审批，提交后的门店与人数仍需核实，不能用页面点击成功替代取号结果。
