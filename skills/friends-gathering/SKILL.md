# 4人聚会程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；桌位或排队说明未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：用当前快照核人数、预算、桌位/包厢、低消与排队原文。未知标明；热门不代表必然排队，不能保证在线取号可用。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户。需要另一份已启用程序时再 `read_skill` 切换；不要声称已发消息、全员同意或取号已成功。
