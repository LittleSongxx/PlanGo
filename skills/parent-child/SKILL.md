# 亲子遛娃 Skill

## 何时命中
用户提到「带娃/孩子/小孩/亲子/宝宝/X岁」时激活。

## 硬约束（进 Verifier，命中即剔除）
- 排除：酒吧、密室、夜店、livehouse、清吧等成人向/危险场所。
- 活动结束建议不晚于 20:00。

## 软偏好（进 Rerank 加权）
- 亲子友好、有母婴室、宽敞、适合儿童、儿童餐。

## 规划建议
1. 优先室内外结合：上午/下午一个亲子乐园或科技馆/动物园（2h）。
2. 正餐选亲子餐厅，点菜自动加"儿童餐/少辣/软烂好嚼"。
3. 加场可选公园 citywalk（天气好）或绘本馆（天气差）。
4. 政策优惠：景点/乐园记得核验儿童票（按身高/年龄）。

## 安全边界
带娃需关注适龄与安全，避免久走、爬坡、过晚活动。本建议非专业育儿意见。
