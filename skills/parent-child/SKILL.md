# 亲子遛娃程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；票务或菜单未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：用当前快照核适龄/身高限制、儿童票与儿童餐原文。母婴室等条件需要来源；缺失标未知，不声称已加餐或下单。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户；不要宣称业务已成功。本程序不是专业育儿意见。
