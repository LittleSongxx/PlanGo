# 亲子遛娃 Skill

## 何时命中
用户提到「带娃/孩子/小孩/亲子/宝宝/X岁」时激活。

## 场景约束
- 排除：酒吧、密室、夜店、livehouse、清吧等成人向/危险场所。
- 活动结束建议不晚于 20:00。

## 软偏好
- 亲子友好、有母婴室、宽敞、适合儿童、儿童餐。

## 规划建议
1. 先问儿童年龄、人数、可用时间与步行耐受，再安排亲子乐园、科技馆等；2h 仅是时长建议，按用户需要调整。
2. 正餐寻找有证据的儿童餐及少辣、易咀嚼选项；菜单缺失时标未知，不声称已加餐或下单。
3. 加场可选公园 citywalk（天气好）或绘本馆（天气差）。
4. 政策优惠：景点/乐园记得核验儿童票（按身高/年龄）。
5. 母婴室、适龄/身高限制和儿童票政策需要来源；Skill 提供约束提示，不代表这些条件已由验证器全部验证通过。

## 安全边界
带娃需关注适龄与安全，避免久走、爬坡、过晚活动。本建议非专业育儿意见。
