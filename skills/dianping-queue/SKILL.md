# 大众点评取号 Skill

## 何时命中
用户想去的热门店需要排队，或用户说「帮我取号/排队/排号」时激活。

## 先核对
- 确认具体门店、就餐人数、儿童是否计入，以及用户当前页面或提供的链接；同名分店不能混用。
- 登录、短信、验证码和距离限制交由用户处理，不绕过限制。页面显示无需排队时如实报告。
- 所有 click/type 都需要对应审批，包括选择人数、填写信息；不能先填好再只确认最后提交。

## 执行步骤
1. 用 navigate 打开用户提供或已观测到的目标门店链接；不能编造取号地址。
2. 用 snapshot/extract 核对门店和排队规则，必要时 scroll 后重新观测。只使用当前快照中实际存在的控件 idx。
3. 依次提出人数选择、输入或提交所需的一个 click/type；Harness 处理对应审批。页面或表单变化后重取快照，不能沿用失效审批。
4. 提交后再 snapshot/extract，保留号码、桌数、时间及来源。页面步骤完成或出现通用“成功”文案仍不能证明取号属于本次门店和人数。

## 暂停与未知结果
- 登录或验证受阻时暂停并交用户接管；没有可用取号页面时说明限制，不生成模拟号码。
- 未核实的业务结果保持 UNKNOWN，不自动重复提交。用户可在网站核对后通过结果界面填写说明与编号。
- 桌数只代表观测时刻，不承诺持续轮询。需要提醒时由用户在提醒界面显式创建，不能声称已经建立实时排队提醒。
