# 大众点评取号 Skill（真实半自动）

## 何时命中
用户想去的热门店需要排队，或用户说「帮我取号/排队/排号」时激活。

## 合规与边界（重要）
- 仅在用户本人已登录的浏览器里，模拟用户手工操作，不绕过登录/短信/风控/距离限制。
- 关键写操作（真正提交取号）必须停在最后一步，由用户两步确认后才点。
- 页面提示需到店附近/距离过远/无需排队/需人工验证时，停止自动流程并如实告知。

## 执行步骤（半自动）
1. browser_navigate 打开该店的大众点评页/取号页（优先用分享链接直达，省 token）。
2. browser_read_page 读取（自动画 Set-of-Marks 编号框），定位「取号/排队」「就餐人数」等控件。
3. browser_type / browser_click 选好人数、填好信息（到"确认取号"前停手）。
4. 生成两步确认卡，等用户点确认后，再 browser_click 真正提交，回传号码/前面桌数。

## 跑不通时降级
- 若需登录/短信/风控挡住：诚实告知，降级用 take_queue_number 模拟取号，并开启桌数轮询 + 到点提醒（scheduleDeparture）。
