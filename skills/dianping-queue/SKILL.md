# 大众点评取号程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；规则未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出或页面已观测到的门店 http(s) URL 时 `navigate`；不要编造取号地址。
3. 核对：用当前快照核对门店、人数规则与排队原文。同名分店不能混用。页面显示无需排队时如实报告。
4. 需审批的写入：选择人数、填写与提交各用一次 `click`/`type`，只使用当前快照 idx；页面变化后重新观测，不能沿用失效审批。
5. 未知或受阻：登录、验证码或距离限制时暂停并交给用户。页面步骤完成或通用“成功”文案不能证明取号属于本次门店和人数；未核实保持未知，不重复提交。
