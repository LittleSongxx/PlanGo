# 陪长辈关怀程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；设施或菜单未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：用当前快照核电梯、坡道、停车、座位与菜单原文。页面缺失时标未知；不能把“商场内”当成无障碍保证，也不根据身份推断身体状况。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户；不要宣称业务已成功。如有医嘱忌口以用户确认为准。
