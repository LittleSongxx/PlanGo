# 减脂友好 Skill

## 何时命中
用户提到「减脂/减肥/轻食/低卡/健身餐/控卡」时激活。

## 硬约束
- 排除：火锅、烧烤、自助、油炸、甜品、蛋糕店、奶茶。

## 软偏好
- 轻食、沙拉、低卡、蒸、高蛋白、健康餐。

## 点菜规则
- 优先蒸煮、白灼、沙拉、高蛋白；避开油炸、糖醋、勾芡、甜品。
- 主食优先粗粮；饮品避开含糖奶茶。
- 先问明确忌口和是否有用户指定的例外，按用户要求保留约束；仅有“轻食”名称不能证明热量或营养达标。
- 用 snapshot/extract 核对菜单原文。没有分量、配料或热量资料时标未知，不编造卡路里，也不因价格比较完成就宣称饮食条件已满足。

## 安全边界
减脂建议为一般饮食参考，非医疗/营养处方。
