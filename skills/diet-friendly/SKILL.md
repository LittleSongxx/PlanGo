# 减脂友好程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；菜单未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：用菜单原文核对该店是否符合用户已确认的饮食条件。没有分量、配料或热量资料时标未知，不编造卡路里，也不因比价完成就宣称饮食条件已满足。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户；不要宣称已点餐或履约成功。本程序是一般饮食参考，不是医疗处方。
