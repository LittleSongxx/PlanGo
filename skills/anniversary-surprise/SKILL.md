# 惊喜纪念日程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。

1. 观测：对当前页 `snapshot` 或 `extract`；政策或菜单未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：用当前快照核外送鲜花/蛋糕是否允许、服务费、配送区域与送达时段。页面未写明则标未知。读取日期不代表已安排提醒。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx；不能批量代填后才确认。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户。页面交互完成不等于配送成功；未核商家、金额和送达要求时保持未知，不重复提交。
