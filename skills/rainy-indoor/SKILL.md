# 雨天室内程序

有界程序：不授权新工具。已加载后只能使用 frontmatter 列出的浏览器操作。`read_skill` 只用于加载或切换程序，不是本程序的业务步骤。准备态禁提交由执行层强制。当前操作集没有单独查天气的接口，不能虚构已调用天气服务。

1. 观测：对当前页 `snapshot` 或 `extract`；天气或场馆说明未读完时 `scroll` 后再观测。
2. 可选导航：仅当用户已给出 http(s) URL 时 `navigate`；不要编造地址。
3. 核对：有匹配日期的来源才陈述天气事实，缺失标未知。室内替代仍需重新核验，不能说已经替换了行程。
4. 需审批的写入：每个 `click`/`type` 单独提出，只使用当前快照 idx。
5. 未知或受阻：登录、验证码或能力不足时暂停并交给用户；不要宣称场馆已开放或业务已成功。
