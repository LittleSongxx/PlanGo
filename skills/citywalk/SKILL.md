# citywalk 小吃 Skill

## 何时命中
用户提到「citywalk/散步/逛/压马路/小吃/打卡/本地特色」时激活。

## 规划建议
1. 选一条步行动线：地标/老街/公园 → 特色小吃 → 咖啡/甜品收尾。
2. 突出本地特色与老字号，兼顾出片点位。
3. 先问出发点、可用时长和可接受步行距离；路线距离、耗时以已有路线证据为准，缺失时标未知。
4. 天气证据表明不适合户外时，建议室内街区/商场替代；未生成并核验新行程前，不说已经替换。

## 软偏好
- 本地特色、老字号、好出片、体验感、网红打卡。

## 信息核对
菜单、营业时间和收费从当前页面 snapshot/extract 核对；“老字号”等身份需要来源，不能只凭店名推断。路线上门店是否营业未知时提醒用户确认。
