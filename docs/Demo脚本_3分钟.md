# 小悠 · Demo 脚本（故事化，记忆 + 主动关心为主线）

> 一句话定位：小悠是一个"越用越懂你、会主动关心你、能自己开美团/点评/小红书办事、还把隐私留在你自己电脑里"的 AI 本地生活助理浏览器。它不重做美团，而是站在美团之上、能操控真实平台且有记忆有温度的工作台。
>
> 对齐美团：定位像"小美/小团"AI 生活小秘书；架构对齐 WOWService 多 Agent 协同（主+子）；能力对齐 LongCat Deep Research（调真实本地生活工具链做"看得见"的调研）；模型用 LongCat-2.0 / MiniMax 可切换。断网时 `DATA_SOURCE=mock` 全程可跑。

## 为什么非得是"AI 浏览器"（答辩必讲，六重价值）

豆包/ChatGPT 也能联网，凭什么要浏览器？因为只有"本机浏览器 + 本地 Agent"这个形态能同时握住六样东西，缺一不可：

1. **身份态**：带你的账号 cookie，看得到你的收藏/券/历史/排队号——服务端匿名抓取拿不到。
2. **真实感知**：真读登录态页面，绕过 app-first/风控，读到真评价真榜单（必吃榜/必玩榜）。
3. **代理行动**：能替你点按/填表/半自动取号，不只是"读+总结"。
4. **长期记忆**：偏好画像沉淀，越用越懂你。
5. **主动陪伴**：连微信后 24h 在线，到饭点/周末/纪念日主动惦记你。
6. **数据主权（重点）**：登录态与记忆只存你本机，不上我们服务器——越懂你也越放心，你是主人不是产品。

一句话：`身份态 × 感知 × 行动 × 记忆 × 陪伴 × 数据主权`，做出 1+1>11。举例："帮这家没开放 API 的小店取个号"——纯 LLM 抓不到登录态、API 没这接口、插件跨不了应用，只有登录态浏览器能办。

## 主线：不是"一次规划"，是"一个会惦记你的助理陪你过周末"

### 0. 开场：它先想起你（20s）
- 打开小悠，顶部一句主动召回："上次带娃去了反斗乐园，娃很爱；老婆在减脂。这周要再安排一次吗？"
- 左下角已自动定位"南山区（IP 区域级）"——桌面无 GPS 也能准到区县。
- 话术："别的助手每次都从零开始问，小悠记得你。"→ 应用效果 / 商业价值（留存）

### 1. 主动关心给灵感（15s）
- 主动关心卡结合天气/时间："明天南山晴，适合户外 + 清淡正餐。"
- 没想法就点左侧"附近发现"，独立窗口弹出你附近的美食/玩乐/咖啡热点。→ 应用效果

### 2. 一句话规划，自动带入记忆（40s）
- 输入："周六下午带老婆孩子出去玩 4 小时，人均 120"——不用再说"孩子 5 岁、老婆减脂"，小悠从记忆自动带入（对话上方"记忆条"显示已带入的偏好，可一键去掉）。
- 看**多 Agent 协同步骤流**：主 Agent 拆解 → 餐饮/玩乐/调研子 Agent 并行 → 记忆子 Agent 带入偏好（仿 WOWService）。
- **天气自适应**：规划前先查本地天气，若周日有雨自动把户外换室内并诚实说明（"今天有雨，已帮你换成室内亲子乐园"）。→ 应用效果
- 成果区出 **3 套差异化方案（经济/均衡/特色）** + 五维雷达 + **页内高德路线**（地铁/时间/距离）。→ 创新性 / 完整性

### 3. 看得见的 AI 浏览器（35s，核心卖点）
- 问："这家店真有那么好？"——小悠自动切到"小悠的电脑"视图，自己打开大众点评：
- **Set-of-Marks** 给可交互元素画彩色编号框（按钮绿/链接蓝/输入紫），合成光标移动 + 点击动画，顶部浮条"小悠正在浏览 大众点评…（可暂停/接管）"。
- 读真实评价正文（Readability）→ 回来汇总成卡片，注明"来自我刚打开的点评页"。→ 创新性

### 4. 攻略视觉导入（15s）
- 甩一张小红书攻略截图 → 视觉识别抽取城市/店/菜品 → 直接改方案。→ 创新性

### 5. 点菜做深 + 比价（30s）
- 正餐同时给**团购套餐**与**单点清单**：单点标"招牌菜" + 针对老婆减脂/孩子的"避雷菜"（油炸高糖/过辣划掉）。
- 比价：单点 vs 团购券后到手价、识别假低价、明确哪个更划算。→ 应用效果 / 商业价值

### 6. 真实半自动取号（25s）
- 热门店要排队 → 取号 Skill：AI 真的打开点评取号页、自动填好人数，**停在最后一步等你确认**（真实半自动；跑不通诚实降级模拟取号 + 桌数轮询）。→ 创新性 / 商业价值

### 7. 顺手加惊喜 + 外卖（20s）
- 孩子想吃蛋糕 → 下单蛋糕到店；纪念日 → 买束花；不想出门那天 → 点外卖（送到家/公司 + 配送费 + 预计送达），均两步确认。→ 应用效果 / 商业价值

### 8. 群体协作闭环（20s）
- 发家庭群确认：二维码给老婆手机（同 WiFi），她投票 + 留"正餐再清淡点" → 一键并入改方案。→ 应用效果 / 社交裂变

### 9. 出发提醒 + 越用越懂（20s）
- 出发前小悠主动提醒："该出发了，前面还剩 2 桌，路上约 20 分钟。"
- 回来后把"娃爱反斗乐园、老婆偏清淡"写进记忆 → 记忆面板可查看/编辑/删除、看到**周末足迹时间线**和"陪你 52 天、去过 6 个地方"（透明可控）。→ 商业价值（留存/忠诚）

### 10. 微信 24h 陪伴（15s，温暖点）
- 右侧"连接"面板扫码连微信（或现场"模拟入站"）：人不在电脑前，直接在微信里跟小悠说"周末看着安排"，它照样办。
- 到饭点/周末/纪念日，小悠主动在微信里惦记你（主动关心同步推送到微信）——**很暖，也是留存钩子**。→ 应用效果 / 商业价值

### 11. 平台化 + 数据主权收尾（10s）
- 右侧"连接"面板：模型可切换（LongCat/MiniMax/DeepSeek/Kimi）、取号/雨天室内/惊喜纪念日/宠物友好等都是可加装 Skill、企业 API 可定制。
- 记忆面板亮出"🔒 数据留在你这台电脑"——隐私本地优先，企业版可私有化模型做到数据不出内网。→ 商业价值（企业级 + 信任壁垒）

## 评分点映射
- 创新性：看得见的 AI 浏览器（Set-of-Marks）+ 攻略视觉导入 + 真实半自动取号 + 多 Agent 协同 + 六重价值论证。
- 完整性：定位 / 天气 / 规划 / 路线 / 点菜 / 交易 / 协作 / 记忆 / 微信 全链路可跑。
- 应用效果：定位准 + 天气自适应 + 主动关心 + 附近发现 + 页内路线 + 响应可见。
- 商业价值：下单转化 + 二维码裂变 + 记忆留存 + 微信 24h 触达 + 数据主权信任壁垒 + Skill/模型/API 平台化。

## 断网 / 兜底预案
- 全程 `DATA_SOURCE=mock` 使用 VitaBench 门店，来源徽章标"数据集"，不依赖外网。
- LongCat 不通时切 MiniMax；取号真实跑不通即降级模拟并标注。
